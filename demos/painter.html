painter

Paint Game

A scribble pad built straight on the Painter API.

Strokes are stored as plain point arrays and redrawn every frame with random blend modes, so old marks keep shimmering.

Painter draws directly on the canvas, Cursor swaps the pointer per tool, and ToggleButtons in a HorizontalLayout form the toolbar.

  • Drag draw or erase with the active tool
  • Click set line start, then line end (line tool)
  • Toolbar switch pencil, eraser, line — or clear all
